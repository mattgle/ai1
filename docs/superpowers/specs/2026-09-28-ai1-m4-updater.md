# AI1 M4: Update checks

**Status:** implemented.
**Extends:** `docs/superpowers/specs/2026-09-21-ai1-design.md`.

## Goal

Tell the owner when a supported tool or bundled extension has a newer version.
Never install an update without a direct user action.

## User flow

- The Electron main process checks for updates at startup, then no more than
  once every 24 hours. It owns one timer for all AI1 windows.
- The owner can run **AI1: Check for Updates** at any time.
- AI1 lists installed and available versions when it can check them.
- The owner can update OpenCode and tmux with one explicit **Update Tools**
  action. AI1 runs Homebrew for those two formulas only.
- Running OpenCode or tmux processes keep their current versions until they
  restart. AI1 does not restart them.
- AI1 and bundled extension updates are notice-only. The owner updates the AI1
  checkout, builds, and installs AI1 by hand. The updater does not modify a Git
  checkout or the installed app.

## Sources and limits

- OpenCode: installed version from `opencode --version`; available stable
  version from Homebrew formula `anomalyco/tap/opencode-v2`.
- tmux: installed version from `tmux -V`; available stable version from
  Homebrew formula `tmux`.
- Bundled VS Code extensions: compare pinned versions from the AI1 root
  `package.json` with the matching Open VSX extension record.
- AI1: compare the current AI1 Git `HEAD` with `origin/main` when AI1 runs from
  its source checkout. Fetch remote metadata to read the current branch tip. If
  AI1 cannot find that checkout, report that the check is unavailable. Do not
  merge, build, or install AI1.
- The first implementation supports macOS with Homebrew. It does not update
  Node.js, Theia, Electron, npm dependencies, or VS Code extensions.

## Safety

- Checks use fixed executable names, fixed formula names, and fixed HTTPS
  endpoints. They do not run shell text from a remote source.
- Homebrew runs only after the owner invokes **Update Tools** or selects that
  action in the update notice. Scheduled checks never run an installer.
- AI1 shows command errors without printing secrets or full environment values.
- A failed source check does not block the rest of AI1 or the other checks.
  Failed automatic checks do not change the saved completion time. AI1 retries
  them after one hour.
- The updater stores its last completed check time in the Electron user data
  folder. It does not store credentials.

## Out of scope

Automatic AI1 or extension installation, signed releases, Windows and Linux,
dependency upgrades, release notes, and automatic restart.
