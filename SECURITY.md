# Security

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/mattgle/ai1/security/advisories/new).
Do not post sensitive details, credentials, or private logs in a public issue.

Include the affected commit or app version, OS, reproduction steps, and expected
security boundary. Remove personal data from attachments. Use an isolated test
workspace. Do not test against another person's files or browser profiles.

## Current status

AI1 is a development preview. No supported app release is available yet.
The public source does not imply verified Linux support or security certification.
See [the release review](docs/public-release-review.md) for known dependency
findings, validation limits, and open release checks.

The project does not promise a response time or a paid bug bounty. Private
reporting is available, but it does not replace security testing before release.
