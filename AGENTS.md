## Task continuation

After completing and verifying a task, continue with the next task in the local
backlog or active implementation plan if it needs no human input. Do not ask for
confirmation only to continue. If a task needs a decision, approval, missing
information, or an unavailable resource, report the blocker and continue with the
next task that needs no human input. Keep existing approval requirements and
restrictions in effect.
